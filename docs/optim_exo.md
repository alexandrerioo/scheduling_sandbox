*Une usine fabrique 3 types de pièces (A, B, C) sur 2 machines. Chaque pièce doit passer sur les deux machines, dans un ordre précis (Machine 1 puis Machine 2). Les temps de traitement sont :*

|  | Machine 1 | Machine 2 |
| --- | --- | --- |
| Pièce A | 2h | 3h |
| Pièce B | 4h | 1h |
| Pièce C | 3h | 2h |

*Chaque machine ne peut traiter qu'une pièce à la fois. On vous demande de minimiser le temps total de production (makespan). Comment modélisez-vous ce problème ? Pouvez-vous proposer une solution algorithmique pour résoudre ce problème ?* 

Attentes : pas de modélisation mathématique, mais plutôt observer l’approche du candidat. Au besoin, le guider sur les notions d’objectif, de contraintes, de variables de décision.
